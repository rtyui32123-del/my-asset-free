# 우리집 자산 현황 (설치형 앱)

가족 순자산과 목표 달성률을 기록하는 앱입니다. 자산 기록은 이 저장소가 아니라 앱을 설치한 기기 안에만 저장됩니다.

## 올리는 방법

1. 깃헙에서 새 저장소를 만듭니다. 공개(Public)로 만들어야 무료로 페이지를 띄울 수 있습니다.
2. 저장소에서 **Add file → Upload files**를 누르고, 이 폴더의 파일을 전부 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
3. **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://<깃헙 아이디>.github.io/<저장소 이름>/` 주소로 앱이 열립니다.

## 휴대폰에 설치

- 아이폰: Safari로 위 주소를 열고 **공유 → 홈 화면에 추가**
- 안드로이드: Chrome으로 위 주소를 열고 **메뉴 → 앱 설치** 또는 **홈 화면에 추가**

## 처음 열었을 때

1. **백업에서 복원**을 눌러 백업 파일(`내자산-백업.json`)을 고르거나 내용을 붙여넣습니다.
2. 화면 위의 **키 넣기**(또는 자산 탭 아래 **시세·환율 수정**)를 눌러 Finnhub 키를 넣습니다. 그 뒤로는 앱을 열 때마다 환율과 미국 주식의 직전 종가를 가져옵니다.
   - 키 받는 법: finnhub.io에서 무료 가입(Get free API key) 후 대시보드에 보이는 API Key를 복사합니다.
   - 키는 이 기기에만 저장됩니다. 환율은 키 없이도 갱신됩니다.

## 주의

- 백업 파일에는 자산 내역이 들어 있으니 이 저장소에 올리지 마세요.
- 기록은 기기마다 따로 저장됩니다. 기기를 바꾸거나 브라우저 데이터를 지우기 전에 앱의 **백업**에서 파일을 받아 두세요.
